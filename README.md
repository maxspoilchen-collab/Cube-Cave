# Game Content

- 3 cave areas, sky rifts, and ancient dungeons.

- Ancient dragons, key quests, iron swords, star swords, and armor.

- Multiplayer co-op support, bot teammates, chat rooms, and a minimap.

# Multiplayer Gameplay

1. All players must first connect to the same Wi-Fi or LAN.

2. The host opens "Block Cave.exe" and selects "Multiplayer Co-op" → "Create LAN Room" from the top menu.

3. Choose between a public or private room; private rooms require a password. Share the displayed IP address and password with your friend.

4. Your friend opens the game, selects "Multiplayer Co-op" → "Join LAN Room," and enters the host's IP address; for private rooms, enter the password.

5. After joining, you can adventure together and use the in-game chat.

**Web-based Multiplayer:** The host starts "Create Web Room" in the game, and your friend joins by opening the web address displayed by the host in their browser.

This is a LAN connection; both players must be on the same Wi-Fi/LAN. To allow friends from outside the network to join, you also need to configure router port forwarding; simply sharing a LAN IP address will not work.
